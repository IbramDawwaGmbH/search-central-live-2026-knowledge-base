Thing · Status code

403

The HTTP status code for a forbidden request; to Googlebot it is a client error and does not slow crawling the way 429 does.

Press and analysis 1

AnalysisD1-C372

Do not answer verified Googlebot with 401, 402 or 403, for example from a login wall, a paywall or a pay-per-crawl setup: Google treats them like 404 and drops the pages, and Google's status code page says not to use 401 or 403 to limit crawling; to slow crawling temporarily, return 429 or 503.
