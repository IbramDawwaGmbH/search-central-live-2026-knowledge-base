Glossary · User-triggered fetchers

Fetchers that request a page because a user asked for it, such as a translation service. Google's documentation says they generally ignore robots.txt, and Google said AI agents acting for a user fall into the same category.

Google’s documentation 2

Documented in

  • List of Google user-triggered fetchers Google · checked 3 October 2026
DocsSourceD1-C138

Google's page on verifying its crawlers says Googlebot and Google's other common crawlers resolve to crawl-*.googlebot.com or geo-crawl-*.geo.googlebot.com host names, special-case crawlers to rate-limited-proxy-*.google.com and user-triggered fetchers to *.gae.googleusercontent.com or google-proxy-*.google.com, and it publishes each group's IP ranges as JSON files such as common-crawlers.json and special-crawlers.json.
