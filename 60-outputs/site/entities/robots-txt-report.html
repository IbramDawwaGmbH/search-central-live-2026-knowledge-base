Glossary · robots.txt report

A Search Console report that shows the robots.txt file as Google last fetched it, with a version history and the errors and successes of each fetch. Google said it uses Google's open-source robots.txt parser.

Google’s documentation 2

Documented in

  • robots.txt report Google Search Console Help · checked 4 October 2026
DocsSourceD1-C140

Search Console's robots.txt report shows the robots.txt files Google found for the top 20 hosts of a Domain property, with their fetch status, warnings and errors; to test whether a specific URL is blocked, Google's help page points to the URL Inspection tool and to Google's open-source robots.txt library.

DocsSourceD3-C667

Google's robots.txt guide says its crawlers update their cached copy of a site's robots.txt every 24 hours, and that the Request a recrawl option in Search Console's robots.txt report refreshes it faster.
