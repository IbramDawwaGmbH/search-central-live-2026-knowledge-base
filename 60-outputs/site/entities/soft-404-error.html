Soft 404

A page that tells users it does not exist (or is empty) but answers with 200; Google treats it as an error and drops it.

Glossary · Soft 404

A page that returns a success code (200) while its content looks like an error or an empty page. Google keeps it out of the index but may keep crawling it. A CDN captcha page served with 200 is a common cause.
