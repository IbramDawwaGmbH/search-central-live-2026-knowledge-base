What Google's documentation says 4

DocsSourceD1-C136

Google's Inside Googlebot post (March 2026) says Googlebot currently fetches only the first 2MB of each URL, HTTP headers included (64MB for PDFs); bytes past that cutoff are not fetched, rendered or indexed, and each resource the page loads has its own separate limit.

Publisher Search Central blog (31 March 2026)
