How things are found

Each thing is a name the event used, with its other names. A claim names it when one of those names is written in the claim, word for word; a few are scoped to the topics where a common word means this thing. A card is a map, not a source: cite the claim IDs on it.

Status codes 8

  • 200200 OK, HTTP 200

    The HTTP status code for success: the server returns the page, and its content can be considered for indexing.

    23 claims · 3 in the docs

  • 403403 Forbidden

    The HTTP status code for a forbidden request; to Googlebot it is a client error and does not slow crawling the way 429 does.

    4 claims · 0 in the docs · 1 not in docs

  • 404404 Not Found

    The HTTP status code for a page that does not exist; Google drops such URLs from the index and crawls them less often.

    24 claims · 7 in the docs

  • 410410 Gone

    The HTTP status code for a page that is gone for good; Google treats it much like a 404.

    7 claims · 3 in the docs

  • 429429 Too Many Requests

    The HTTP status code for too many requests; Google treats it like a server error and slows crawling.

    10 claims · 3 in the docs

  • 4xx4xx errors, client errors

    The class of HTTP status codes for client errors; apart from 429 they do not slow Google's crawling.

    8 claims · 1 in the docs

  • 503503 Service Unavailable

    The HTTP status code for a temporarily unavailable server, the right answer for planned maintenance and short outages.

    7 claims · 2 in the docs

  • 5xx5xx errors, server errors, server error

    The class of HTTP status codes for server errors; Google slows crawling when it sees them and drops URLs that keep returning them.

    12 claims · 4 in the docs
