# Private notes

**Anything about my own sites, clients or employer, plus the list of claims marked `private: true`.**

> [!CAUTION]
> **Private: this folder never leaves this computer.** Only this `README.md` is in git. Everything else here is ignored by `.gitignore`, never committed and never included in a shared output. Back it up yourself.

## <img src="../_system/brand/icons/map.svg" width="24" height="24" alt=""> What's here

| File | What it holds | Made by |
| --- | --- | --- |
| `private-claims.md` | Every claim marked `private: true`, with its session | Generated by every build |
| My own notes | Notes about my own sites, clients or employer | Hand |

The build leaves the private claims out of every shared output and lists them in `private-claims.md` instead. Do not edit that file: change the claim in `20-claims/` and run `rebuild.bat`.

## <img src="../_system/brand/icons/lock.svg" width="24" height="24" alt=""> How to use it

- **Keep my own work here.** Nothing about my own sites, clients or employer goes into `20-claims/`. It goes here.
- **Make a claim private** by adding `private: true` to it in `20-claims/dayN.yaml` and rebuilding. A misspelled or repeated `private` key is a build error, so a typo cannot publish a private claim.

> [!NOTE]
> A claim marked `private: true` is still stored in the tracked `20-claims/dayN.yaml`; only its generated listing lives here. Anyone with the repository can read it. See *Known item* in [`PRIVACY.md`](../PRIVACY.md).
